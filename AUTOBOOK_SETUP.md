# AutoBook Studio
Open AutoBook from the V3 navigation or Layout Studio. Upload JPEG/PNG/WebP files, set trim dimensions and usable pages, then Generate. First-page solo is optional. Layflat pairs adjacent usable pages; a final unpaired page remains single. Panorama toggle on two-photo spreads uses one full spread photo plus an inset, preserving both photos. Drag to swap within a spread, use crop controls, replace photos, regenerate grid, lock, and preview. Save project downloads a JSON containing original photos; keep it private. PNG export is trim size at selected pixel resolution (DPI setting determines pixels; PNG metadata may not encode DPI). Multiple downloads may require browser permission. No cloud upload, PDF, bleed, color profile, or printer certification. Existing calculators remain unchanged; AutoBook uses its own balanced distribution (portrait max 4, other max 8). No database migration needed. Browser testing still required.
